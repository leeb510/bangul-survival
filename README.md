# 방울섬 서바이벌 (PWA)

폴더째로 정적 웹 호스팅에 올리면 바로 실행되는 웹게임이에요. HTTPS 주소여야 홈 화면 설치와 오프라인 실행이 됩니다.

## 올리는 방법 (택 1)
- **Netlify Drop**: https://app.netlify.com/drop 에 이 폴더를 끌어다 놓기
- **GitHub Pages**: 저장소에 파일을 올리고 Settings > Pages에서 배포

## 휴대폰에 설치
- 안드로이드 크롬: 주소 열기 → 메뉴 → "홈 화면에 추가" (또는 "앱 설치")
- 아이폰 사파리: 공유 버튼 → "홈 화면에 추가"

## 파일
- `index.html` 게임 전체 (그림·소리 모두 코드로 그려서 별도 이미지 없음)
- `manifest.webmanifest` 앱 이름·아이콘·가로 화면 설정
- `sw.js` 오프라인 캐시 (게임을 고친 뒤엔 `CACHE` 이름의 숫자를 올려 주세요)
- `icon-192.png`, `icon-512.png` 앱 아이콘
